# AdventureWorks Business Intelligence Dashboard | Power BI

## 📌 Project Overview

This project involves developing an interactive Business Intelligence dashboard using Microsoft Power BI Desktop, based on the AdventureWorks case study.

AdventureWorks is a fictional global manufacturing company specializing in cycling equipment and accessories.

The main objective is to analyze business performance across sales, revenue, profit, product returns, regional performance, product trends, and customer behavior through interactive dashboards.

## 🎯 Business Objectives

- Monitor key business performance indicators (KPIs).
- Analyze overall sales, revenue, profit, and product returns.
- Compare business performance across different geographical regions.
- Evaluate product-level performance against targets.
- Understand customer purchasing behavior.
- Identify high-value customers and their contribution to revenue.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** – Dashboard development and visualization.
- **Power Query Editor** – Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** – Calculated columns and measures.
- **Data Modeling** – Relationships between fact and dimension tables.
- **CSV Files** – Data sources.

## 📊 Dashboard Pages

### 1. Executive Dashboard

Provides an overview of overall business performance through key KPIs and interactive visualizations.

**Key Metrics:**
- Total Revenue: ₹24.9M
- Total Profit: ₹10M
- Total Orders: 25K
- Return Rate: 2.17%

**Visualizations:**
- Revenue trend analysis.
- Orders by product category.
- Monthly revenue, orders, and returns.
- Product performance and return analysis.
- Most ordered and most returned product types.

### 2. Regional Map

Displays geographical sales distribution across different regions.

**Features:**
- Interactive geographical map.
- Regional filters for Europe, North America, and Pacific.
- Country-level sales visualization.
- Interactive region selection.

### 3. Product Details

Provides detailed insights into individual product performance.

**Key Features:**
- Selected product analysis.
- Monthly orders versus target.
- Monthly revenue versus target.
- Monthly profit versus target.
- Price adjustment parameter.
- Total and adjusted profit comparison.
- Product return trend analysis.
- Product metric selection using interactive controls.

### 4. Customer Details

Focuses on customer-level analysis and purchasing behavior.

**Key Metrics:**
- Unique Customers: 17K
- Revenue per Customer: ₹1,431

**Visualizations:**
- Total customers trend.
- Customer distribution by income level.
- Orders by occupation.
- Top 100 customers by orders and revenue.
- Top customer identification.
- Revenue and order analysis for selected customers.
- Year-based filtering.

## 🔄 Project Workflow

### 1. Data Connection & Transformation
- Connected raw CSV files to Power BI.
- Cleaned and transformed data using Power Query.
- Used data profiling tools.
- Modified data types and prepared tables for analysis.

### 2. Data Modeling
- Created a relational data model.
- Worked with fact tables and dimension tables.
- Established relationships using primary and foreign keys.
- Applied cardinality and filter direction concepts.

### 3. DAX Calculations
- Created calculated columns and measures.
- Practiced row context and filter context.
- Used aggregation and logical functions.
- Worked with CALCULATE, FILTER, and iterator functions.
- Developed measures for revenue, profit, orders, customers, and returns.

### 4. Interactive Dashboard Development
- Created KPI cards and charts.
- Implemented slicers and filters.
- Used drill-down and drill-through features.
- Explored bookmarks and visual interactions.
- Developed interactive product and customer analysis pages.

### 5. Performance Optimization
- Explored Power BI optimization features.
- Used Performance Analyzer.
- Learned about query reduction and optimization presets.
